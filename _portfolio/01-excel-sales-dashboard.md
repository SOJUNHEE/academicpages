두잇로지스 재직 중 인터지스 남동센터의 월 운영 자료로 처음부터 직접 만든 회사 업무용 Excel 대시보드다. 화주 10곳의 일자별 보관·입고·출고 매출을 하나의 데이터 시트로 모으고 피벗테이블·함수·차트·슬라이서로 현황을 한 화면에서 보게 했다. 원본은 실제 화주사 정보가 담긴 회사 자료라 공개하지 않고, 같은 구성을 가상 데이터로 다시 만든 재현 예시를 싣는다.

## 한눈에 보기

| 수치 | 의미 |
|---|---|
| **5개** | 피벗테이블 (일자·월·분기·화주·매출 항목) |
| **8개** | 슬라이서로 조건 전환 (회사 원본 기준 · 공개 재현본은 3개) |
| **10곳** | 화주 일자별 보관·입고·출고 매출 |
| **7일 → 3일** | 월 마감 소요일 (두잇로지스 실제 경력 · 여러 업무 개선의 결과, 이 대시보드는 마감 대조에 사용) |

## 배경 · 문제

- 월간 물동량·화주별 매출 시트가 따로 있어, 월 운영 매출을 볼 때마다 시트를 하나씩 열어 합계와 비교를 손으로 계산해야 했다.
- 보고서를 쓸 때마다 표와 차트를 새로 만들어야 했다.
- 자료는 입력·보관만 되고 일자·화주·기간별 비교를 따로 하지 않으면 현황을 한눈에 볼 방법이 없었다.

## 목표

- 자료를 입력하고 보관하는 데서 끝나지 않고, 업무에 필요한 현황(일자·월·분기·화주별 매출, 매출 비중, 전월대비 증감률)을 한눈에 파악할 수 있게 하는 것을 목표로 했다.

## 데이터

- 실제 회사 데이터: 인터지스 남동센터 화주 10곳의 일자별 보관·입고·출고 매출(2024년 1~2월 운영 자료).
- 원본은 실제 화주사 이름과 매출이 담긴 회사 자료라 공개하지 않는다. 포트폴리오에는 화주·날짜·금액을 모두 가상으로 바꾼 재현 예시(SAMPLE DATA)만 싣는다.

## 해결 방법

- 실무 데이터 정리: 월간 물동량·화주별 매출 시트를 정리해 화주 10곳의 일자별 보관·입고·출고 매출을 하나의 데이터 시트로 구성했다.
- 피벗테이블로 집계: 피벗테이블 5개로 일자·월·분기·화주·매출 항목별로 집계했다.
- 함수로 데이터 관리: SUM·AVERAGEIF·ROUND·ROUNDUP·IFERROR로 물동량·매출을 계산하고, GETPIVOTDATA로 전월대비 증감률과 매출 비중을 계산했다.
- 현황 시각화: 차트 5개와 슬라이서 8개(회사 원본 기준)로 조건을 바꿔 가며 매출 현황을 한 화면에서 확인하게 했다.

## 주요 기능

- 일자별·월별·분기별 매출 차트로 기간에 따른 매출 흐름을 바로 볼 수 있게 했다.
- 화주별 총매출과 보관·입고·출고 매출 비중으로 어느 화주와 어느 작업에서 매출이 나는지 확인할 수 있게 했다.
- 전월대비 증감률을 GETPIVOTDATA로 계산해, 보고 때 매번 따로 계산하지 않게 했다.
- 분기·월·화주 슬라이서로 조건을 바꾸면 모든 표와 차트가 함께 바뀌게 했다.

## 구조

- Excel 통합 문서 하나(회사 원본 기준 시트 9개): 데이터 시트 → 피벗테이블 5개 → 차트 5개와 슬라이서 8개로 이어지는 구조다. 원본 데이터를 고치면 피벗을 새로 고쳐 모든 표와 차트가 함께 바뀐다.
- 공개 재현본(가상 데이터)은 시트 4개·피벗테이블 5개·슬라이서 3개·차트 5개로, 원본의 핵심 집계·필터 기능만 다시 만든 예시다. 실무 원본은 회사 자료라 공개하지 않는다.

## 내 기여와 팀의 역할

**내가 맡은 일**

- 데이터 시트 구성 (화주 10곳 일자별 보관·입고·출고 매출)
- 피벗테이블 5개·함수·차트 5개·슬라이서 8개 대시보드 제작
- 월 운영 보고·정산·마감 대조에 사용
- 공개 범위 결정: 원본 비공개, 가상 데이터 재현본만 공개

## AI 활용 방식

- 원본 대시보드는 회사 업무로 처음부터 직접 만들었습니다. AI는 포트폴리오에 공개할 재현본을 만드는 데만 썼습니다: 실제 화주사 정보를 빼고 같은 구성을 가상 데이터로 다시 만들었습니다.

**AI에 맡긴 일**

- 공개용 재현본 제작 (가상 데이터로 같은 구성)
- 재현본의 피벗·슬라이서 동작 점검

**직접 판단한 일**

- 원본 대시보드 설계와 제작 (데이터 시트·피벗·함수·차트·슬라이서)
- 월 운영 보고·정산·마감 대조에 실제 사용
- 공개 범위 결정: 원본 비공개, 재현본만 공개

**검증**

- 재현본에 실제 화주사 이름·금액이 남아 있지 않은지 확인하고, 화면과 파일에 SAMPLE DATA로 표시했습니다.

## 결과

- 월 운영 보고(상사·본사), 화주별 매출·물동량 현황 확인, 화주사별 정산과 월 마감 대조에 실제로 사용했다.
- 두잇로지스 재직 중 월 마감 소요일을 7일에서 3일로 줄였고, 이 대시보드는 그 과정에서 정산·마감 대조에 쓴 도구다. 단축 전체가 이 대시보드 하나의 효과라고 따로 측정하지는 않았다.
- 원본은 공개하지 않고, 같은 구성을 가상 데이터로 재현한 Excel 파일과 화면을 SCM 포트폴리오에서 볼 수 있다.

## 한계와 개선 과제

- 지금은 운영 자료를 시트에 옮겨 넣는 수작업이 남아 있다. WMS 자료를 바로 불러오는 연결(Power Query 등)을 쓰면 입력 시간을 더 줄일 수 있다(향후 적용 가능).
- 같은 사고방식을 웹으로 옮겨, 여러 화주·상품군의 실적과 정산을 한 화면에서 보는 다품종 3PL 운영 대시보드(개인 프로젝트)로 확장했다.
